Snake Game

Projeto de um jogo inspirado no clássico Snake Game, desenvolvido utilizando HTML, CSS e JavaScript puro, sem o uso de frameworks ou bibliotecas externas.

O principal objetivo do projeto foi trabalhar o funcionamento e a lógica da página, utilizando JavaScript para controlar a movimentação da cobra, as colisões, o sistema de pontuação e o crescimento da cobra.

Funcionamento
A cobra se movimenta pelo tabuleiro utilizando as setas do teclado:
 ArrowUp — move para cima
 ArrowDown — move para baixo
 ArrowLeft — move para a esquerda
 ArrowRight — move para a direita
A cobra possui uma cabeça e partes do corpo que acompanham seu movimento.
Ao consumir uma maçã, a pontuação aumenta e a cobra cresce.
Após uma maçã ser consumida, uma nova maçã é posicionada aleatoriamente no tabuleiro.
O jogo verifica se a cobra ultrapassou os limites do tabuleiro.
Também é verificado se a cabeça da cobra colidiu com o próprio corpo.
Ao perder, o jogo é temporariamente bloqueado e uma tela de erro é exibida com uma contagem regressiva antes de permitir uma nova partida.
O contador registra a quantidade de maçãs consumidas durante a partida.
🛠️ Tecnologias utilizadas
HTML5 — estrutura da página e dos elementos do jogo.
CSS3 — estilização do tabuleiro, cobra, maçã e telas do jogo.
JavaScript — lógica principal, movimentação, colisões, geração das maçãs, pontuação e controle do estado do jogo.
